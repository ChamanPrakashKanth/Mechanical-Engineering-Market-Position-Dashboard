For AI agents and developers

Connect an agent to engineering career analysis.

MechIntel provides a portable Agent Skill and a local, read-only Model Context Protocol server for profile analysis, role alignment, skill gaps, ATS keyword coverage and career roadmaps.

Local-first · deterministic · no model API or GPU

What an agent can do

Analyze a profile

Call existing readiness indicators and interpret them with clear limits.

Compare role lanes

Match skills, tools, specialty, certifications and project evidence against the role catalog.

Plan a next step

Identify catalog gaps and make a pathway plan from user-provided facts.

Review keywords

Measure coverage of a fixed 13-term list. This is not an employer ATS score.

Run the local MCP server

Node.js 20+ is required. From a cloned repository:

npm ci --prefix mcp
npm run sync-catalog --prefix mcp
npm test --prefix mcp

Configure your MCP client to launch node /absolute/path/to/repository/mcp/server.mjs over stdio. The local server needs no API key and sends no requests to a model or remote service.

Install the Agent Skill

The canonical skill is in .agents/skills/mechintel/. Copy that directory into the agent's documented skills folder. Codex, Claude Code, Cursor and compatible-agent instructions are in its SKILL.md.

A public SKILL.md does not automatically register or activate it. The client must support Agent Skills and load or install the folder.

Scoring and privacy limits

The website and MCP share deterministic scoring functions. The comparison cohort is synthetic—not real or anonymized applicants. Score and role-fit values are heuristics, not hiring probabilities, real applicant ranks, live vacancy counts, or guarantees.

Resume text is processed in memory by a local server and is not persisted or returned. The optional Cloudflare Worker is separate from GitHub Pages. No remote endpoint is currently deployed.
