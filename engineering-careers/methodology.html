Engineering Career Intelligence Desk

Trust & methodology

What the engineering benchmark can—and cannot—say

A precise number is not useful if its source is misleading. This page defines the evidence boundary.

Dataset identity

The file engineering_reference_profiles.json contains generated synthetic reference profiles. It contains no scraped resumes, real applicants, survey respondents, names, contact details or device identifiers. Synthetic records are not described as anonymized people.

Scoring method

The evidence-readiness score assigns 65% to detected domain foundations and 35% to evidence signals such as projects, experience, testing, validation and measured outcomes. Keyword detection is explainable but imperfect: absence from a resume does not prove absence of a skill. The synthetic position compares that score with 200 generated records in the selected domain. Ties share the same position.

Permitted interpretation

The dataset can test scoring behavior and show how a profile compares with a fixed reference distribution. It cannot establish a percentile among engineers, predict hiring, measure current employer demand, or represent any country’s workforce.

Demand and skill-map boundary

Skill priority values are editorial starter weights, not counts from current vacancies. The product deliberately does not label them as live demand. A future demand index must publish its job sources, collection dates, geography, deduplication method and sample size.

Zero-retention architecture

The engineering-wide desk processes resume and skill text only in page memory. PDF extraction occurs locally with PDF.js. The only same-site request is for the static synthetic reference file and does not contain user input. The desk has no profile submission endpoint, account database, advertising pixel, profile cookie, local-storage write or server-side career-history store. Inputs disappear when the page is refreshed or closed. The separate legacy mechanical learning application may store course progress locally and is not covered by this zero-retention claim.

Future real-data standard

If permissioned human data is introduced, publish the sample dates, geography, recruitment method, inclusion rules, sample size, missing-data handling, weighting, refresh cadence and privacy basis. Report small cohorts as insufficient rather than manufacturing precision.

Career guidance limits

Editorial skill maps are starting hypotheses. Users should verify them against current employer vacancies, official professional bodies, accreditation requirements and local regulations.
