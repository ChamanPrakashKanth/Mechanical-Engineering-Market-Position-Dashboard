How to calculate a mechanical tolerance stack-up

Start at one surface of the functional gap and trace a single dimension loop through the features that locate the opposing surface. Enter dimensions that increase the gap as “+” and dimensions that reduce it as “−”. The tool sums signed nominal values, then evaluates the lowest and highest possible gap by moving each dimension to the unfavorable drawing limit.

Worst-case minimum: add each “+” feature at its minimum size and each “−” feature at its maximum size. Worst-case maximum: add each “+” feature at its maximum size and each “−” feature at its minimum size. These arithmetic bounds cover all combinations within the stated limits for this linear 1D model.

RSS is not a guaranteed limit. The optional RSS output is an estimate only when each symmetric tolerance is a centered ±3σ process width and the contributors are independent. Drawing limits alone do not prove these assumptions. Use worst-case bounds when guaranteed interchangeability is required; use actual process data and a qualified analysis for production decisions.

Worked bearing and spacer example

For housing length +40.20 mm (+0.04/−0.00), bearing A width −10.00 mm (+0.02/−0.02), spacer length −20.00 mm (+0.03/−0.01), and bearing B width −10.00 mm (+0.01/−0.02), nominal gap is 0.20 mm. The exact worst-case range is 0.14 to 0.29 mm. Against a 0.10 to 0.30 mm requirement, this example passes both limits.

What this tool does not model

This is not a GD&T solver. It does not model geometric tolerances, datum mobility, angular or 2D/3D effects, thermal expansion, deformation, surface finish, assembly sequence, selective assembly, or measured process capability. Verify the complete functional loop and applicable drawing requirements with qualified engineering review.

Frequently asked questions

What does a negative minimum gap mean?

A negative lower bound means interference is possible within the entered dimensional limits. The simple calculator does not decide whether that interference is acceptable.

Can I enter asymmetric tolerances?

Yes. Enter the upper and lower tolerance magnitudes separately for each feature. The worst-case calculation uses each stated limit directly. RSS is disabled for asymmetric rows.

When should I use RSS instead of worst case?

Use the optional RSS estimate only when the required process assumptions are supported: symmetric centered ±3σ widths and independent contributors. RSS is not a substitute for worst-case checks where guaranteed fit is required.

Method reference

The RSS combination principle combines independent standard uncertainty components by root-sum-of-squares. See NIST Technical Note 1297, combined standard uncertainty. NIST TN 1297 is measurement-uncertainty guidance; applying RSS to manufacturing dimensions requires separate evidence for the stated process assumptions.
