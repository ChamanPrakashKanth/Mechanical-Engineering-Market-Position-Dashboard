What is included?

Thin-wall and bellows shapes are geometry studies: printability, flexibility and strength are not established. Each part includes an STL mesh and an editable .scad source. Circular sweeps use 96 segments; the rounded ring section uses 24 points. STL is a faceted format and does not encode units: select millimetres when importing. These downloads do not include STEP or native SolidWorks files.

These are simplified educational models, not standardized catalog hardware. No fit tolerances, material properties, threads or load ratings are specified. Confirm suitability before fabrication.

How do I change the dimensions?

  1. Download a part’s OpenSCAD source.
  2. Open it in OpenSCAD and edit the named dimensions at the top. Keep dimensions positive; for hollow parts, keep the inside diameter smaller than the outside diameter.
  3. Render the model and export a new mesh. Check dimensions in your CAD or slicing application.

Can I use these models commercially?

MechIntel releases these original geometries under CC0 1.0 Universal. Attribution is appreciated but not required. There is no warranty or certification. File dimensions, not preview scaling, define the geometry.
